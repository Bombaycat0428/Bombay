世界の猫図鑑 PREMIUM

愛らしい猫たち、全9種類の魅力に迫る

スコティッシュフォールド

原産国：スコットランド / 特徴：折れ耳

折りたたまれた耳が最大の特徴。のんびりとした温和な性格で、運動量も少なめなため、室内で非常に飼いやすい人気の猫種です。

マンチカン

原産国：アメリカ / 特徴：短い足

短い足でトコトコと歩く姿が愛らしい猫。足は短いですが、非常に活発でジャンプ力もあり、好奇心旺盛で人懐っこい性格です。

ラグドール

原産国：アメリカ / 特徴：長毛・青い目

「ぬいぐるみ」という名前の通り、抱っこされるのが大好きな大型の猫。青い瞳とふわふわの毛並みが美しく、とても従順で落ち着いています。

アメリカンショートヘア

原産国：アメリカ / 特徴：渦巻き模様

クラシックタビーと呼ばれる渦巻き模様が特徴。陽気で賢く、環境適応能力も高いため、初心者でも非常に飼いやすい猫です。

ベンガル

原産国：アメリカ / 特徴：レオパード柄

ヒョウのような美しい模様を持つ猫。野生的な見た目ですが、性格は大人しく人懐っこいです。運動量が非常に多く、遊ぶのが大好きです。

シャム（サイアム）

原産国：タイ / 特徴：ポインテッドカラー

顔や耳、足に濃い色がつくポイントカラーとサファイアブルーの目が特徴。とても賢く、おしゃべりで、飼い主に忠実な猫です。

ノルウェージャンフォレストキャット

原産国：ノルウェー / 特徴：長毛・大型

北欧の森で生まれた、ダブルコートの厚い被毛を持つ大型猫。とても賢く、穏やかで我慢強いため、他のペットや子供ともうまくやれます。

メインクーン

原産国：アメリカ / 特徴：最大級・長毛

「ジェントルジャイアント（穏やかな巨人）」と呼ばれる、イエネコ最大級の猫。とても知性的で人懐っこく、犬のような性格と言われます。

ロシアンブルー

原産国：ロシア / 特徴：ブルー・エメラルドアイ

光沢のあるブルー（グレー）の被毛とエメラルドグリーンの目が美しい猫。ボイスレスキャットと呼ばれるほど鳴き声が静かで、大人しいです。
